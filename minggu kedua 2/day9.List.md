Ringkasan Hari 9

1.List adalah "keranjang" yang bisa menyimpan banyak data sekaligus dalam satu laci, ditulis dengan tanda kurung siku [ ].
2.Isi list dipisahkan dengan koma, contoh: ["Budi", "Rina", "Andi"].
3.Index pada list dimulai dari 0, sama seperti string.
4..append(...) menambahkan data baru ke akhir list.
5.list[posisi] = isi_baru mengganti isi list di posisi tertentu.
6..remove(...) menghapus data tertentu dari list (berdasarkan nilainya, bukan posisinya) — akan error kalau datanya tidak ditemukan.
7.len(list) menghitung berapa banyak isi di dalam list.
8.for item in list: adalah cara mengambil setiap isi list satu per satu, tanpa perlu tahu jumlah isinya.
9.List bisa digabung dengan if/else di dalam loop, untuk mengecek setiap isinya satu per satu.
10.Jangan pakai nama bawaan Python (seperti list, str, int, print) sebagai nama laci — itu akan menimpa fungsi aslinya.
